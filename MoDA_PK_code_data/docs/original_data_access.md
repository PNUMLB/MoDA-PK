# Data access and redistribution boundary

The local bundle contains the complete processed input used for the current primary evaluation and the available collected legacy raw material. This is not a claim that all ten original source archives are present or that all data may be redistributed.

Existing source-license evidence is preserved at `data/provenance/catalog/evidence/MDFUSE_GRU_SOURCE_LICENSE_AUDIT_KO.md`. That audit identifies CC0 Dryad sources and package-sourced data with their own terms, but does not establish row-level redistribution grants for some Monolix examples. Consequently the complete mixed-cohort rows and observation-level predictions remain Git-ignored by default. Aggregated analysis and source manifests remain reviewable.

Use the source catalog, original URLs, package/version evidence and SHA256 manifests to recover authorized inputs. A universal automated downloader is not included. Pretrained molecular representations and historical raw digitization provenance have additional documented limitations. Do not describe the locally supplied raw directory as a fully reconstructed original-data archive.

The older seven-drug v6 cohort and restricted-infusion 17-drug cohort are separate analyses; their files do not expand the current primary cohort count. NIDA-restricted material is not introduced by this release.
